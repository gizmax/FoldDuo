# B43 "Výkon jako feature" — hand-written Baseline Profile (AGP/ART "Human Readable Profile" format).
#
# This is NOT generated from a device trace: there is no Macrobenchmark module wired up yet (out
# of scope for this patch — see below), so the rules below are a best-guess list of the classes/
# methods that sit on the launcher's cold-start path and the unfold morph's hot path, written by
# hand from reading the code (MainActivity's onCreate, LauncherScreen's first composition,
# MorphController's per-frame reads, FoldShader/FoldEffect's shader plumbing, PoseRepository's
# sensor pipeline, systemfrost's overlay). `androidx.profileinstaller` (app/build.gradle.kts)
# ships this file as `assets/dexopt/baseline.prof`+`.profm` and installs it as a compiler profile
# the first time the app runs after install, so ART's background dexopt AOT-compiles these methods
# instead of interpreting/JITing them cold on the first few launches — the same mechanism Play
# Store's "cloud profiles" use, just seeded locally instead of from aggregated device data.
#
# Rule syntax (one per line):
#   <flags><class descriptor>-><method signature>   -- a method rule
#   <flags><class descriptor>                        -- a whole-class rule (preload/verify)
#   flags: H = Hot, S = Startup, P = Post-startup (any combination, e.g. HSP)
#   wildcards: `*` matches within one path/name segment, `**` matches across segments
#
